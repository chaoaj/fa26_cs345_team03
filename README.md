## Whimsy & Woe ##

Whimsy & Woe is a single-player, browser-based deck-building strategy game.

## Description ##

Players select an animal-themed class, assemble decks, and engage in turn-based combat against enemies and bosses using action cards powered by consumable energy cards. The game features a unique "Sanity" system in place of traditional health, emphasizing distinct playstyles, unlockable cards, and satisfying progression.
